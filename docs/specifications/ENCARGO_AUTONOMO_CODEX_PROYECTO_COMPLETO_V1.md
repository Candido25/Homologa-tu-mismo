# Encargo autónomo Codex proyecto completo V1

Este documento registra el alcance técnico autorizado y la precedencia aplicada en la rama `codex/transicion-vercel-supabase`.

## Precedencia

1. Documento maestro de definiciones cerradas V1.
2. ADR-004 GitHub + Vercel + Supabase sin Azure.
3. Paquete de participación y privacidad piloto V1.
4. Matriz de preproducción V1.

6. Documentación histórica Azure, solo como antecedente.

## Lotes técnicos

- Lote 0: recuperar ciclo de piloto cerrado, migración 0010, semillas ficticias y pruebas.
- Lote 1: plataforma Vercel/Supabase, Auth, PostgreSQL, aislamiento y feature flags cerradas.
- Lote 2: diagnóstico versionado sin clasificación jurídica por palabra clave.
- Lote 3: checklist versionado, regenerable y comparable históricamente.
- Lote 4: gestión documental ficticia privada con hashes, cuarentena, retención, bloqueo y purga.
- Lote 5: OCR/IA simulada con evidencias, confianza, idempotencia, derivados, revocación y resistencia a instrucciones incrustadas.
- Lote 6: guía de sede y Tasa 107 separada.
- Lote 7: seguimiento, administración, pagos ficticios, gobierno y auditoría.

## Criterio de avance

La ausencia de credenciales Vercel, Supabase, OpenAI, Polar, DNS, RUC o datos comerciales definitivos no bloquea el trabajo técnico. Esas capacidades quedan simuladas o fallan cerradas.
